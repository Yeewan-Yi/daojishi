# 有期 · Youqi

属于两个人的倒计时与回忆地图，支持浅色、深色、手机布局和共同传书。

三维地球上的飞机从西雅图出发，沿反方向的较长大圆弧线抵达南京。位置按真实起止时间计算，100% 停在南京。上滑放大地球后，国界逐渐显现，共同去过的南京和绍兴亮起。点击国家可聚焦查看共同足迹；城市回忆使用现有双人传书保存，支持文字、图片和 emoji。

国界数据来自 [Natural Earth 1:110m Admin 0 Countries](https://www.naturalearthdata.com/downloads/110m-cultural-vectors/110m-admin-0-countries/)，属于公有领域，已随网站部署，无需第三方地图请求。城市位置使用市区代表点，地图用于纪念与浏览。

页面采用开放式单页布局，航线直接呈现在背景上，起止时间以文字排版展示，不使用卡片堆叠。

顶部仅保留一个「编辑」入口。起止日期为对齐的静态信息，时间使用逐位翻页显示；只有变化的数字翻动，系统减少动态效果设置下直接更新。

## 独立视觉实验

`experiments/golden-wheel.html` 是金纺轮灵感的独立交互预览，含拖动旋转、松手惯性、暂停、键盘和示例进度控制。使用原创 SVG 几何图形，参考链接位于预览页底部；不读取或写入 Supabase，不出现在正式页，也不包含在 GitHub Pages 发布包内。可直接用浏览器打开该 HTML，或使用本地预览路径 `/experiments/golden-wheel.html`。

## 功能

- 编辑标题、开始时间与截止时间，按秒更新；未开始时倒数到开始，开始后倒数到截止，结束后归零。
- 开始时间决定总周期进度；截止时间必须晚于开始时间，周期最长 100 年。
- 本地保存设置，同一浏览器的普通标签页之间同步修改。
- Supabase 云端共享：固定链接、双向自动同步、共同编辑/仅查看权限、版本冲突保护、断线重试。
- 分享链接携带标题与绝对时间，支持中文与表情，自动换算到接收者设备时区。
- 深浅主题、专注模式，以及悬停向右展开文字的几何导航。
- 页面未能立即就绪时显示飞机从左向右的加载航程，资源就绪后抵达并淡出；快速加载时跳过。
- 自定义日期日历，年份、月份和时分支持滚轮调整；日历区域滚轮切换月份，Shift + 滚轮切换年份。
- 双人传书支持 emoji、每封最多 3 张图片、图片草稿、粘贴/拖入图片、历史缩略图及大图查看。上传前转换为最长边 1600 像素、最大 1.2 MB 的静态 JPEG。
- 编辑、分享、日期选择、图片预览及表情面板有进出过渡，并尊重系统减少动态效果设置。
- 无构建步骤，无 JavaScript 第三方依赖。字体服务不可用时自动使用系统字体。

## 共同使用

1. 编辑好标题与时间，点击「分享倒计时」。
2. 点击「开启共同使用」，将当前倒计时保存到云端。
3. 选择「共同编辑」或「仅查看」，复制生成的固定链接给对方。
4. 双方使用同一份共享倒计时，保存后自动同步。设备会记住最近打开的共享链接；之后打开首页，会恢复该设备最近的共享倒计时。

页面可见时约每 2 秒检查更新，隐藏后约每 15 秒检查。网络延迟、浏览器节流或休眠可能延长间隔，重新回到页面或网络恢复时会立即尝试刷新。此版本使用轮询，而非 WebSocket 推送。秒数在本地每秒计算，不上传每秒计时数据。

同时编辑会通过数据库行锁与版本号阻止旧内容覆盖新内容。断网时显示上次同步缓存，保存失败会保留编辑窗口中的草稿，不会显示为保存成功。

开启共同使用前仍可复制快照链接，旧版 `#c=...` 链接继续可用。快照后续修改不会同步。首页本身不代表任何全站共用的倒计时，首次访问必须使用生成的共享链接才能进入同一份记录。

## 数据与访问权限

云端记录保存到 `youqi_private.countdowns`，表启用 RLS 且不向 `anon`、`authenticated` 授予直接访问权限。三个限定参数的数据库函数负责创建、读取、更新，均锁定 `search_path`，没有动态 SQL。

- 共同编辑凭证为浏览器生成的 256 位随机值，数据库仅存 SHA-256 哈希。
- 仅查看凭证由数据库生成独立的 256 位随机值，只有编辑者能通过 API 取得它；查看者无法读取编辑者凭证，也不能写入。
- 凭证放在 URL fragment 中，API 请求通过 HTTPS 在请求正文传递。获得链接的人即获得对应权限，不限人数，也不绑定特定身份；请只分享给信任的人。
- 创建接口是面向网站访客的公开接口，不需要登录；当前没有账号系统、链接撤销和过期功能。如要公开推广，应增加创建限流、身份与生命周期管理。
- `config.js` 仅包含可公开的 Project URL 与 Publishable key，绝不能加入数据库密码、Secret key 或 service_role key。

Supabase 的安全检查可能提示受限的 `SECURITY DEFINER` 函数可由访客执行，以及私有表启用了 RLS 却无策略。这是本方案的显式设计：表本身拒绝直接访问，数据操作仅经过校验访问凭证的函数。`supabase/verify.sql` 在真实数据库中验证查看权限、错误凭证、版本冲突与直接访问拒绝，并回滚测试记录。

## 配置云端

项目已连接 Supabase。若部署到自己的新项目：

1. 在 SQL Editor 中运行 `supabase/setup.sql`，保留 Data API 开启。
2. 在 `config.js` 填写自己的项目根 URL（不含 `/rest/v1/`）和 Publishable key。
3. 若需要传书，依次运行 `supabase/letters.sql`、`supabase/letters-media.sql`。图片桶 `youqi-letters` 保持私有，不授予客户端直接访问。
4. 部署 `supabase/functions/youqi-media/index.ts` 为 `youqi-media` Edge Function。函数使用房间凭证与个人凭证认证，因此关闭网关 JWT 验证；后端通过环境中的 Secret key 或 service_role key 操作存储，浏览器仅持有 Publishable key。
5. 执行 `supabase/verify.sql`、`supabase/verify-letters.sql`、`supabase/verify-letter-images.sql` 核对权限，再推送部署。这些 SQL 验证均回滚测试数据。

不需要关闭 RLS、启用匿名登录或向前端提供数据库管理员密钥。图片访问链接由后端核验身份后签发，有效期一小时；轮询只读取图片元数据，图片不会随着每秒倒计时重复下载。

## 地球放大

首屏持续反向滚动或下拉可直接放大原有地球。放大上限比原版略大；背景、地表和菜单保持原样，倒计时始终显示。向下滚动收回放大后，同一段滚动继续进入倒计时界面；复位可平滑恢复视角与大小。

## 双人传书

电脑端鼠标移入右下角「传书」展开独立侧栏，主界面同步让出宽度，地球、倒计时和菜单在剩余区域重新居中，不覆盖倒计时；仅查看时移出 240 毫秒后收起。输入框获得焦点后进入持续编辑状态，原生输入法候选窗引起的失焦（无论下一焦点为空、页面或代理控件）、鼠标遮挡和选词提交均不解除保护；候选提交后的 500 毫秒忽略误传的鼠标与 Esc 事件。仅明确点击侧栏外、Tab 离开或主动收起才结束编辑保护，编辑时显示收起按钮。键盘可聚焦入口并按 Enter，非输入法组词状态下 Esc 收起，组词时 Esc 仅交给输入法取消候选。手机轻触入口打开底部留言页，支持关闭按钮与遮罩关闭，并按可视窗口高度避让软键盘。收起和刷新保留未发送的草稿，修改留言的草稿与新留言草稿分开。

开启云端共享后，在留言簿填写两个人的称呼，生成两条独立身份链接。分别保存各自链接，持有链接即可跨设备识别身份；普通倒计时分享不附带留言身份。首次创建的设备也保存两条链接以便再次复制；其他设备只能取得自己的链接。身份凭证在 URL fragment 中，数据库仅保存其 SHA-256 哈希，不保存可还原的个人密钥。无账号模式下，请妥善保存链接。

每条留言最多 500 个 Unicode 字符，保留换行，以纯文本渲染。最新在前、每页 20 条，以递增序号翻页，避免同时新增导致历史跳项。前台打开留言时约 2.5 秒检查一次，收起时降低频率，后台约 15 秒；网络延迟可能延长。正在翻旧留言时显示更新提示，不抢滚动位置。本人可修改、删除自己的留言；更新校验版本，发送 UUID 支持幂等重试，后台限制两次新留言至少相隔三秒。删除后正文替换为占位内容且不再对两端返回。

数据库增量定义见 `supabase/letters.sql`，后台验证见 `supabase/verify-letters.sql`（测试事务回滚，不污染实际记录）。`public.youqi_letters` 是 invoker 包装，授权逻辑位于未暴露的 `youqi_private.letters_rpc`；所有新表启用 RLS、无客户端表权限，仅经过房间及个人随机凭证校验的操作可访问。新增房间索引支持历史读取。

数据库检查器会提示私有表「RLS 开启但无策略」，这里刻意拒绝一切直接表访问；参见 [RLS 检查说明](https://supabase.com/docs/guides/database/database-linter?lint=0008_rls_enabled_no_policy)。部署前已存在的公开倒计时 definer 函数提示未由本功能新增；新留言入口使用 invoker 包装，相关检查说明见 [函数执行权限](https://supabase.com/docs/guides/database/database-linter?lint=0028_anon_security_definer_function_executable)。

进度数字绘制在球面曲面网格上并随地球转动。视角变斜、文字转到背面或屏幕边缘时，进度接续到飞机旁；飞机也在背面时使用地球边缘指示。显示切换有阈值回差，避免在边缘反复闪动。进入倒计时界面后，进度恢复为界面上的横向进度条。

## 字体说明

网页字体：倒计时数字采用 Libre Baskerville，航程百分比与航行数字采用 IBM Plex Mono，其余数字采用 Times New Roman。汉字使用项目所有者提供的方正宋刻本秀楷简体，保留原字体字符覆盖并转换为 WOFF2，同源加载；数字通过独立字体范围避免被中文字体替换。数字字体及许可见 `fonts.css` 和 `vendor/FONT-LICENSES.txt`，方正字体说明见 `THIRD_PARTY_NOTICES.md`。

## 时间说明

使用设备时钟与目标绝对时间的差值计算，而不是每秒累减，因此休眠、切换后台或重新打开后会重新校准。精度仍依赖设备系统时间。编辑时按设备当地时区输入，共享时保存 UTC 时间。

航程百分比保留七位小数，前两位小数正常大小、后五位缩小显示。暗色地球使用左上方暖色侧光与较弱的冷色轮廓光，保持背景克制。传书发送按钮为「递函」。
