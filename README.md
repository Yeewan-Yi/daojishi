# 有期 · Youqi

一个安静、简洁的倒计时网页。暖白与鼠尾草绿配色，支持深色模式、手机布局和桌面浏览器悬浮小窗。

主视图以飞机跨越地球半球展示时间进度：飞机沿半圆航线行进，实线为已走过的航迹，虚线为剩余航程。50% 位于航线顶点，100% 停在目的地，不循环播放假进度。数字仅作辅助。未开始时等待起飞，结束后显示已抵达；悬浮小窗复用同一视图。地球轮廓为示意插画，航线表达时间进度，不代表真实地理航班。

页面采用开放式单页布局，航线直接呈现在背景上，起止时间以文字排版展示，不使用卡片堆叠。

顶部仅保留一个「编辑」入口。起止日期为对齐的静态信息，时间使用逐位翻页显示；只有变化的数字翻动，系统减少动态效果设置下直接更新。

## 独立视觉实验

`experiments/golden-wheel.html` 是金纺轮灵感的独立交互预览，含拖动旋转、松手惯性、暂停、键盘和示例进度控制。使用原创 SVG 几何图形，参考链接位于预览页底部；不读取或写入 Supabase，不出现在正式页，也不包含在 GitHub Pages 发布包内。可直接用浏览器打开该 HTML，或使用本地预览路径 `/experiments/golden-wheel.html`。

## 功能

- 编辑标题、开始时间与截止时间，按秒更新；未开始时倒数到开始，开始后倒数到截止，结束后归零。
- 开始时间决定总周期进度；截止时间必须晚于开始时间，周期最长 100 年。
- 本地保存设置，同一浏览器的普通标签页之间同步修改。
- Supabase 云端共享：固定链接、双向自动同步、共同编辑/仅查看权限、版本冲突保护、断线重试。
- 分享链接携带标题与绝对时间，支持中文与表情，自动换算到接收者设备时区。
- 深浅主题、专注模式、支持 Document Picture-in-Picture 的桌面浏览器中的置顶悬浮小窗。
- 无构建步骤，无 JavaScript 第三方依赖。字体服务不可用时自动使用系统字体。

## 共同使用

1. 编辑好标题与时间，点击「分享倒计时」。
2. 点击「开启共同使用」，将当前倒计时保存到云端。
3. 选择「共同编辑」或「仅查看」，复制生成的固定链接给对方。
4. 双方使用同一份共享倒计时，保存后自动同步。设备会记住最近打开的共享链接；之后打开首页，会恢复该设备最近的共享倒计时。

页面可见时约每 2 秒检查更新，隐藏后约每 15 秒检查；悬浮小窗打开时保留较快检查。网络延迟、浏览器节流或休眠可能延长间隔，重新回到页面或网络恢复时会立即尝试刷新。此版本使用轮询，而非 WebSocket 推送。秒数在本地每秒计算，不上传每秒计时数据。

同时编辑会通过数据库行锁与版本号阻止旧内容覆盖新内容。断网时显示上次同步缓存，保存失败会保留编辑窗口中的草稿，不会显示为保存成功。

开启共同使用前仍可复制快照链接，旧版 `#c=...` 链接继续可用。快照后续修改不会同步。首页本身不代表任何全站共用的倒计时，首次访问必须使用生成的共享链接才能进入同一份记录。

## 数据与访问权限

云端记录保存到 `youqi_private.countdowns`，表启用 RLS 且不向 `anon`、`authenticated` 授予直接访问权限。三个限定参数的数据库函数负责创建、读取、更新，均锁定 `search_path`，没有动态 SQL。

- 共同编辑凭证为浏览器生成的 256 位随机值，数据库仅存 SHA-256 哈希。
- 仅查看凭证由数据库生成独立的 256 位随机值，只有编辑者能通过 API 取得它；查看者无法读取编辑者凭证，也不能写入。
- 凭证放在 URL fragment 中，API 请求通过 HTTPS 在请求正文传递。获得链接的人即获得对应权限，不限人数，也不绑定特定身份；请只分享给信任的人。
- 创建接口是面向网站访客的公开接口，不需要登录；当前没有账号系统、链接撤销和过期功能。如要公开推广，应增加创建限流、身份与生命周期管理。
- `config.js` 仅包含可公开的 Project URL 与 Publishable key，绝不能加入数据库密码、Secret key 或 service_role key。

Supabase 的安全检查可能提示受限的 `SECURITY DEFINER` 函数可由访客执行，以及私有表启用了 RLS 却无策略。这是本方案的显式设计：表本身拒绝直接访问，数据操作仅经过校验访问凭证的函数。`supabase/verify.sql` 在真实数据库中验证查看权限、错误凭证、版本冲突与直接访问拒绝，并回滚测试记录。

## 配置云端

项目已连接 Supabase。若部署到自己的新项目：

1. 在 SQL Editor 中运行 `supabase/setup.sql`，保留 Data API 开启。
2. 在 `config.js` 填写自己的项目根 URL（不含 `/rest/v1/`）和 Publishable key。
3. 执行 `supabase/verify.sql` 核对权限，再推送部署。

不需要关闭 RLS、启用匿名登录、安装 SDK 或提供数据库管理员密钥。

## 本地运行

需要 Node.js 22 或更新版本，无须安装依赖：

```sh
node scripts/serve.mjs
```

打开 http://127.0.0.1:4173 。

```sh
node --test
node --check app.js
node --check countdown.js
node --check cloud.js
```

## GitHub Pages

仓库的 `.github/workflows/pages.yml` 会在推送 main 后自动检查并部署。仓库 Settings → Pages → Source 应设为 GitHub Actions。仅上传公开静态文件，不上传 SQL、测试、说明文档或其他工作文件。

## 悬浮小窗

Windows 常驻桌面版本位于 [desktop](desktop/README.md)，支持可选置顶、托盘、开机启动、加密保存共享链接。与下面的浏览器悬浮窗独立，可在关闭浏览器后继续运行。安装包和便携版在仓库 Releases 中提供。

在支持 `window.documentPictureInPicture` 的 HTTPS 桌面浏览器中点击「悬浮小窗」。小窗保持置顶，与原页面的时间、标题和主题同步。必须保留原网页；关闭原网页后小窗随之关闭。浏览器可能限制尺寸与外观，不支持时会提供专注模式入口。

## 时间说明

使用设备时钟与目标绝对时间的差值计算，而不是每秒累减，因此休眠、切换后台或重新打开后会重新校准。精度仍依赖设备系统时间。编辑时按设备当地时区输入，共享时保存 UTC 时间。
