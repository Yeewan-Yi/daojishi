开始只需要这几步

  1. 登录自己的 GitHub，点上方「复制开发仓库」，创建自己的 Fork。无需提供密码，也不需要主仓库写权限。
  2. 用 GitHub Desktop 把自己的 Fork 克隆到电脑，并创建分支，例如 codex/our-story。用 VS Code 或自己习惯的 AI 编辑器打开文件夹。
  3. 安装 Node.js 24 LTS，在项目终端执行下面三条命令。把「新篇」改成你准备开发的页面名字。
npm ci
npm run new:page -- our-story "新篇"
npm start

浏览器打开 http://127.0.0.1:4173/pages/our-story/?mode=local。主要修改 pages/our-story/ 中的三个文件即可。

  1. 完成后运行 npm test，在 GitHub Desktop 提交并推送自己的分支，点 Create Pull Request，目标选择 Yeewan-Yi/daojishi → main。
  2. 对方审核合并后自动上线。新页面会出现在本页下方的目录中，再安排正式导航入口。

交给 AI 编辑器的开工说明

把以下文字直接复制给你的 AI，再补充你想做的功能：

请先阅读根目录 AGENTS.md、CONTRIBUTING.md 和 docs/subsite-design.md。
我负责一个独立子网站，请先帮我创建 pages/our-story/，标题为「新篇」。
复用 shared/subsite.css、shared/subsite.js 和现有字体图标，沿袭有期/拾光风格。
优先只修改自己的页面目录；不要改主站、真实共享数据或数据库权限。
使用 ?mode=local 做演示。需要跨设备同步或上传资料时，先用演示数据做好界面，
并在合并请求说明数据结构和接口需求，由主项目统一接入。
开发完成后运行 npm test，说明测试结果，再提交 Pull Request。
