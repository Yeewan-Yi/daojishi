# 有期 / 拾光 / 共议：使用验收记录

日期：2026-10-26。共议的界面调整先经 PR #6 上线，本轮随后检查使用流程并修复问题。

## 方法与数据边界

- 用独立本机来源、合成照片和演示身份操作，不读取、改名、移动或删除两人的正式相册、书信、评论。
- 为照片评论增加 1.8 秒延迟，相册保存增加 1.5 秒延迟，主动在请求完成前切换照片、继续输入、按 Escape。
- 另用完全本机的模拟共享接口测试倒计时保存：2.4 秒延迟、503 失败、保留草稿后重试。此模拟不访问正式数据库。
- 使用 45 张合成照片（原有 3 张加 42 张分页资料），覆盖首批 20 张、后续续载、月份筛选及查看器跨页切换。
- 检查桌面、768 像素平板、390 和 320 像素手机宽度。视口测试不等于真实 iOS / Android 设备认证。

## 已复现并修复

| 问题 | 复现方式 / 影响 | 修复与复验 |
| --- | --- | --- |
| 照片评论请求清空其他草稿（高） | A 照片发送后立刻切至 B 写字；或等待发送时继续在 A 写字。原请求完成会清空当前输入。 | 请求按照片隔离，捕获提交文本与重试 ID；只清除该照片仍未改变的草稿。两条路径均在延迟请求下复验，另有回归测试。 |
| 保存期间可提前关闭窗口（中） | 相册保存未结束时按 Escape，可退出窗口并继续操作；共享倒计时存在同类窗口生命周期风险。 | 保存期间锁住窗口及控件，拦截 Escape、背景关闭及排队中的关闭动画；完成或失败后恢复。相册慢保存、共享保存成功和失败重试均复验。 |
| 批量选择状态跨城市残留（中） | 南京进入选择影像，再切绍兴；点击照片仍进入选择。 | 城市切换清理选择模式与选中集合。切换后点击照片正常打开查看器。空相册禁用无意义的选择入口。 |
| 筛选为空时像是整座城市没有照片（中） | 切空相册或只筛选视频，出现邀请导入的通用空态。 | 明确显示“还没有符合筛选的回忆”，提供“查看全部影像”一键清理相册、月份、类型筛选；两种空态均复验。 |
| 本机图片预览反复创建地址（中） | 同一照片重复打开会产生不同 Blob URL，缩略图与查看器的重复请求也不能共享。 | 本机预览也缓存 URL、合并在途请求。重复打开复验使用相同地址；云端签名 URL 的过期规则保持原样。 |
| 损坏照片报错难理解（低） | 导入损坏的 PNG，原生解码异常直接显示。 | 在解码边界转成中文可操作提示，保留待导入队列。移除坏文件后选择正常图片可以继续上传。 |

同时补齐日期编辑、分享、照片查看、上传和相册窗口的可访问名称，并统一窗口过渡模块的版本引用，避免多个模块实例各自持有关闭 / 保存状态。
