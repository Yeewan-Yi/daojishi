# 共议数据与交互

入口在有期、拾光及公共模板的顶部导航。主站进入所有网站的总览；子站进入本站范围。图标使用两页交叠的信笺与修订勾线，悬停在右侧展开「共议」。点击在当前页面右侧展开共议，表单与讨论均在侧栏内完成。

建议包含一段正文、1–8 个目标网站、固定来源网站、作者、时间及处理状态。网站标记单独排在正文上方，例如「【有期】【拾光】」，不把归属拼进正文。状态为待议、审议中、修订中、已修订、暂缓、暂不采纳、已转交。转交选择新的目标，保留原站和全过程；原站仍可查看它提出的建议。

## 存储与权限

- `youqi_private.suggestion_books`：每个房间的单调递增 revision，用于轻量检查更新。
- `youqi_private.suggestions`：正文、来源、目标、作者、状态与版本。
- `youqi_private.suggestion_events`：回复、状态变更和转交事件。包含操作人、时间、前后状态与前后归属。
- 全部表启用 RLS 并撤销客户端直接访问。`public.youqi_suggestions` 是 invoker 包装，调用私有 schema 中的严格能力校验逻辑；每次读取与写入均同时核对房间和独立个人密钥，不允许仅凭房间链接冒充双方身份。
- 两个人在同一个房间内均可回复和更新进展；其他房间完全隔离。只存文本，不上传媒体，无需增加存储桶。
- 单条建议最多 2000 字，回应/流转说明最多 1000 字。每个房间最多 10000 条建议；每人每天最多新建 60 条、回应或处理 300 次。历史按 20 条建议、30 条事件分页读取。
- 提交 UUID 在网络重试与页面刷新时复用，避免重复创建；状态修改必须带版本，冲突时保留输入，不覆盖对方的进展。
- 侧栏打开时前台每约 5 秒检查 revision，后台约 20 秒；关闭时暂停轮询。返回页面和恢复网络时立即检查。属于轮询同步，网络和浏览器休眠会影响延迟。输入框不因收到更新而被重建。
- `?mode=local` 只使用独立的演示存储，明确提示不向对方同步。未接入个人身份时，提示从专属链接进入，不生成伪身份或放宽权限。

## 接入与验证

新增 SQL 位于 `supabase/suggestions.sql`，应由主项目统一应用。它只添加共议对象，不修改已有倒计时、传书或影像记录。公共模板自动入口说明见 `docs/subsite-design.md`。

验证：`npm test`、`node scripts/check-subsites.mjs`、`node scripts/verify-suggestions-db.mjs`。数据库检查使用 PGlite 的合成房间，不读取真实双人资料。真实云端联调用一次性测试房间验证双方读写、跨房间拒绝、身份冒用拒绝、转交、重复提交和版本冲突，完成后删除测试房间。

## 页内共议与输入标记

共议在当前页面右侧展开，不再单开子页面。`initSubsite()` / `mountSuggestionLink()` 的接入方式保持兼容，新页面自动获得侧栏。关闭后保留建议和回复草稿；原共议网址会回到对应页面并展开侧栏。

输入开头的 `【拾光】建议正文` 会自动识别归属；`【有期】【拾光】建议正文` 指定多个网站。名称取自注册目录，也可用 `【page:our-story】` 或 `【our-story】`，总站别名为 `【总站】`。只有开头的标记会被解析，正文中的括号保持原样。未知或重名标记会提示更正，避免误投。子网站的原始归属始终保留，其他标记可增加目标。

本机预览：`index.html?mode=local&council=1`。模板开发仍用本机演示，不需额外数据库或凭证。

## 常驻输入、多选与回应提醒

新增建议输入框固定在侧栏上方，讨论列表独立滚动。归属与进展使用横向多选：同组 OR，两组 AND，全部清空该组限制。有期归属使用草绿、拾光使用淡蓝；新站可在 registry 条目提供 themeColor（六位十六进制颜色）。显式选择有期仅匹配有期归属；全部网站才是总览，保留子站来源追溯规则。列表与详情的提议时间位于正文上方，提议人单独强调。

list 兼容旧 site/status，同时支持 sites/statuses 数组（最多 64 个站点、7 个状态），先过滤再按原游标分页，不在前端只筛已加载记录。activity 为只读接口，仍校验同一房间与独立个人身份；只返回对方的回复摘要，每页 50 条，按 seq 正序补收。新增一个部分索引，不新增私人资料表、不放宽权限。升级 SQL 见 migrations/20261025124938_council_filters_activity.sql。

页面开启后约 10 秒检查一次新回应，后台约 60 秒，恢复网络或回到页面立即检查；不要求共议侧栏保持打开。未读数显示在共议图标，手机更多按钮保留提醒点；点提醒可直达讨论，打开对应讨论后按已读取的事件序号清除。首次启用只建立基线，避免把全部历史当新消息。游标、未读及阅读记录按房间与个人在本机存储，同一浏览器标签页同步，设备之间不共享阅读状态；不请求浏览器推送权限，网页完全关闭时不会发出系统通知。
