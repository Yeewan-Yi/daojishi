# 有期 · Windows 桌面小组件

Windows 10/11，.NET Framework 4.8。原生 WinForms 程序，无需浏览器常开。

运行 `Youqi-Setup.exe` 安装到当前用户，或解压便携版运行 `YouqiWidget.exe`。首次使用时，在网页点击“分享”，复制完整链接粘贴到小组件。支持编辑链接及只读链接，遵循现有网页的访问权限。

- 拖动空白区域移动，记住位置。窗口默认不置顶。
- 点击“钉住”切换置顶；点击“编辑”打开同一共享倒计时的完整网页。
- “···”或托盘右键：外观、共享链接、立即同步、开机启动、隐藏、退出。
- 关闭窗口会隐藏到托盘；退出请使用菜单中的“退出”。
- 默认跟随系统主题，开机启动默认关闭，需要自行开启。便携版开启后请勿移动程序；移动后需重新开启。
- 每秒更新剩余时间，每 8 秒读取一次云端；网络请求超时 12 秒，失败后下轮重试。对方修改通常在 8 秒加网络请求耗时内显示。
- 离线继续显示上次同步的数据并明确标记。小组件只读取云端；编辑由完整网页完成。
- 共享链接和离线缓存使用 Windows 当前用户 DPAPI 加密保存在 `%LOCALAPPDATA%\YouqiWidget\settings.dat`，不会写入安装包。完整分享链接代表访问权限，请只发给希望共享的人。
- 升级时先从托盘退出旧程序，再运行新安装包；配置和云端时间保留。

卸载：先关闭开机启动并退出，删除 `%LOCALAPPDATA%\Programs\YouqiWidget`、桌面及开始菜单的有期快捷方式。需要清除本机设置时再删除 `%LOCALAPPDATA%\YouqiWidget`；这些操作不会删除云端数据。

从源码构建：PowerShell 执行 `./desktop/build.ps1`，输出位于 `desktop/dist`。无需 NuGet 或管理员权限。`WidgetTests.exe --cloud` 只读验证本机已配置的共享记录，不创建或修改数据。
